// Struttura narrativa dei frame (viaggio al contrario) Frame 001 → "PORTFOLIO" // Landing: il risultato finale (sciame rosso) Frame ~064 → Invasione rossa // Gli Astrofagi: il brief difficile Frame ~096 → Sciame caotico // Metà scroll: il processo creativo Frame 192 → Atmosfera verde di Adrian // Fine scroll: la genesi // La sequenza è esportata già al contrario: il visitatore rivive // il viaggio dall'obiettivo alla genesi, dal risultato alla radice.

Snippet della logica principale: canvas scroll-driven e motore di particelle reattive al mouse.

// ── CANVAS SCROLL-DRIVEN (scroll invertito HD) ────────────── function updateBgFrame() { const maxScroll = document.body.scrollHeight - window.innerHeight; const progress = Math.min(1, window.scrollY / maxScroll); // DIRETTO: progress 0 → frame_001 ("PORTFOLIO" visibile in cima); // frameCount è auto-rilevato dalla cartella ./frames, non hardcoded const target = Math.round(progress * (frameCount - 1)); if (target !== currentFrame) { currentFrame = target; renderFrame(currentFrame); } } // ── GRAVITAZIONE MAGNETICA PARTICELLE ─────────────────────── function updateParticle(p, mouse) { const dx = p.x - mouse.x, dy = p.y - mouse.y; const dist = Math.sqrt(dx*dx + dy*dy); if (dist < ATTRACT_R && dist > ORBIT_R) { // zona attrazione: particella risucchiata verso il mirino const f = Math.pow(1 - dist/ATTRACT_R, 1.6) * ATTRACT_STR; p.vx -= (dx/dist) * f; p.vy -= (dy/dist) * f; } else if (dist <= ORBIT_R) { // zona orbita: respinta per creare coda circolare const f = (1 - dist/ORBIT_R) * 2.2; p.vx += (dx/dist) * f; p.vy += (dy/dist) * f; } p.vx *= 0.958; p.vy *= 0.958; // attrito p.x += p.vx; p.y += p.vy; }
